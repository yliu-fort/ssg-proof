# Round-17 verification scripts

The root agent's own exact-arithmetic checks of claims made in round 17
(by routes or by the paper audit) before they entered `frontier.tex`.
Everything uses `fractions.Fraction`; nothing here imports the routes' or
auditors' code.

| Script | What it checks | Outcome |
| --- | --- | --- |
| `signdef_damping.py` | The paper audit's counterexample to the (now struck) claim in `rem:signdef` that the sign-definite class of `def:signdef` is closed under `def:damping`. Builds the 9-vertex stopping game, damps every edge by a chain of `m` average vertices exactly as `def:damping` prescribes, and recomputes `d^v` from the first-passage laws. | `G` is sign-definite (`d^v = (0,0,1/4)`); `G_m` is not for `m = 1..4` (`(0,-1/16,3/32)`, `(0,-9/128,45/256)`, ...), matching the closed form `(0, -l^2(1-l)/2, l^2(2-l)/4)`, `l = 1-2^-m`. |
| `bh_count.py` | `prop:blowup-height`'s former clause that a maximal-height set has `2^k` vertices: exhaustive over all 728 acyclic unique sink orientations of the 3-cube (self-contained USO / acyclicity / height code). | 32 orientations have a non-power-of-two number of maximal vertices (24 with six, 8 with seven); the auditor's example `(2,3,1,0,6,7,4,5)` has heights `(2,2,1,0,2,2,2,2)`. |
| `ol_verify.py OL3_GAME.json` | The order-lattice route (`ol:`): (1) `ol:unique` exhaustively over ALL total preorders on the letters of 76 random stopping games (up to 4 controlled vertices, up to 4683 preorders each), every tie-breaking of the decode; (2) `ol:lift-cycles` from the game `OL3_GAME.json` (23 non-sinks): stopping, all 8 profile values and out-sets against `thm:cyclic-uso`'s table with Min's actions exchanged, profile-nondegeneracy, `w*`, the antipodal walk's 3-cycle and the lift from the coarsest preorder; (3) `ol:small-C` on 2000 random separated nondegenerate 1-Max-1-Min games. | All as claimed: the only consistent preorder is the true one and decodes to `w*`; OL3 cycles with period 3 through `(0,0,0),(1,0,1),(0,1,1)` and 6 of 8 profiles enter the cycle; no cycle with two controlled vertices. |
| `bp_verify.py OS_roots_1-4_1-2.json OS5_GAME.json` | The parametric-path route (`pp:`): BP(D) rebuilt from the statement's successor lists for D = 1..8 (N = 10D+2); values of the damped game by exact backward induction (the game is acyclic). Checks the tent identity `phi_d = T^d(beta) e_d` at 14 rationals per level, that the ties are exactly at `k/2^D` with exactly `F_d, G_d` tied, that the 2^D optimal pairs are pairwise distinct, constant inside each interval, and equal to the tent itinerary. Then the route's one-Max instances: `val(u_0)-val(u_1) = c beta^K prod(beta - r_i)` with the files' own roots. | All as claimed for D = 1..8; the 17-vertex instance has roots {1/4,1/2} (c = 1/2, K = 4), the 94-vertex one roots {1/8,...,5/8} (c = 1/8, K = 15). The statement's OS_2 (roots {1/2,3/4}, 19 vertices) was not dumped by the route and is not checked here. |
| `b2pins.py B2_pin137_GAME.json` | The realisation-space route's new realisations of $B^2$ (`rs:verified`), through the round-16 sparse verifier `sparse_verify.py` (needs `auso.py` from the harness): stopping, all 32 Max strategies against both Min strategies, outmap against the paper's $B^2$, ties, USO, acyclicity, height, the run from 12. | The 137-, 138- and 139-vertex games all realise $B^2$ exactly (no tie, USO, acyclic, height 10, the printed run, values increasing); the 137-vertex one is archived here. |
| `pd_discount.py` | Whether `thm:fold`'s $P_D$, read as a discount game, has any breakpoint (the parametric-path route's claim that the naive transplant of the fold dies). | For $D\le7$ the pair $F_1,G_1$ is tied at every $\varrho$ ($\val X_1=\val Y_1=\varrho^2/4$) and the optimal set never changes. |
| `rs_upclosed.py` | The pin-pair step of `cor:pinned-no-doubling` (supplied by the realisation-space novelty audit): for $B^2$ and its four doubling translates, which of the ten coordinate pairs has both switchable sets on its rest layer closed under improving single switches of the other coordinates. | For $B^2$ only $(\alpha_2,\beta_2)$ passes (0 violations; the others 12,3,5,9,1,7,9,6,6); at $(\alpha_2,\beta_2)$ the translates by $8,10,24,26$ have $3,3,5,5$ violations; $(\alpha_1,\beta_2)$ passes for the translate by 26, which is why the pin-pair step is needed. Cube arithmetic: sink 4, height 10, maximal $\{12,14,28,30\}$, cap $10+2+4$. |
| `bc_light.py BC_*.json` | The oracle-barrier route's family BC(e,s) (its game files): the root's own slack calculus, min-plus closure and ratio calculus, Z-seeded, both clauses at every controlled vertex, 40 rounds. | BC(2,5): M2 fires at $v_0$ at round 39, M2T at 21, M6 never; BC(3,5), BC(4,5): all silent for 40 rounds (the certificate guarantees $2, 5, 11$). |
| `bc_verify.py BC_*.json` | The same with the full Z-seeded own-successor hybrid (transport LP included), few rounds, plus $w^*$ against the file, the gap $2^{-s}$ at $v_0$ and the seeds. | see the round README |
| `dout3.py` | The query-model route's number $D_{\mathrm{out}}(3)=4$: exact minimax decision tree for naming the sink of an unknown AUSO of the 3-cube from out-set queries, over all 728 AUSOs (each realised by a stopping SSG, `prop:m3-realised`). | $4$, with $1$ and $2$ for the 1- and 2-cube classes. |
| `ol_gc.py` | The order-lattice correctness auditor's 8-vertex non-separated game on which the decode-and-re-sort iteration 2-cycles while the antipodal walk converges. | reproduced: the lift alternates $(1,0),(0,1)$; the walk reaches the sink $(0,0)$. |
| `bc_m1.py` | `def:simorder`'s greatest fixed point (the root's `t_standing.simorder`) on the BC games: soundness, transitivity, the four order tests at each controlled vertex. | sound, transitive, none of the twelve pairs related, at all three sizes. |
